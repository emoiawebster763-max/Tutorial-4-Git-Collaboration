# Tutorial 4: Git Collaboration Workflow
## Purpose 
This repository was created to demonstrate how to use Git and Git hub for collaboration
##Steps followed 
1. Installed Git on my computer.
2. Created a Github account.
3. Created a public respiository.
4. Created a new branch.
5. Added a text file to the repository.
6. Commited and pushed the changes.
7. Created a Pull Request.
8. Asked my collaborator to review and aprove the Pull Request.
9. Merged the approval Pull Request.
